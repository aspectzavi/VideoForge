# VideoForge

Professional AI-powered video processing toolkit built on FFmpeg.

## Planned Features

- Vertical video generation
- Automatic captions
- AI reframing
- Silence removal
- Face tracking
- Batch processing
- Social media export presets
- Timeline-based editing engine

## Technology Stack

- Python
- FFmpeg
- Faster-Whisper
- OpenCV
- MediaPipe
- Rich
- Typer
- Pydantic
